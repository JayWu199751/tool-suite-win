# 04：性能条与按指标采样

**What to build:** 在统一宿主中显示和配置性能条，保留指标、位置、全屏隐藏及多显示器能力；按启用指标查询，支持隐藏、停用和重新启用。

**Blocked by:** 01 — 统一宿主与独立数据启动

**Status:** resolved

**实施结果：** 性能条以模块形式接入统一宿主，保留 CPU/内存/GPU/显存/网络/时间与温度显示、指标选择、全屏自动隐藏、手动显隐、贴靠与多显示器位置恢复；只查询已启用指标，隐藏时暂停采样与时钟，恢复后重建差分基线。`PerfMonitor.Core.Tests` 161、`PerfMonitor.Windows.Tests` 50、`PerfMonitor.App.Tests` 22 通过；真实硬件缺失组合与多显示器/DPI 人工场景未执行，见[工单 09 验证](../docs/validation/ticket-09.md)。

**规格：** [工具套件合并规格](../spec.md)。主要覆盖用户故事 20–24、38、40 中的性能条行为。

## 已确认约束

- 复用现有性能条核心控制器、平台采样与窗口实现，接入统一宿主，不保留原独立 App、托盘、自启或提权交接进程。
- 指标不可用表示缺失，不等于零；继续允许现有短命查询进程，不新增 GPU 厂商适配。
- 配置、日志和布局使用套件存储，不读取或改写原应用配置。

## 验收条件

- [ ] 原有 CPU、内存、GPU、显存、网络、时间及适用温度读数能显示；保留原有指标选择、刷新率、字体、透明度和布局设置。
- [ ] 指标段顺序、自然宽度、窗口样式、任务栏行摆放、位置吸附及多显示器位置恢复符合原行为。
- [ ] 硬件、驱动或查询不可用时显示缺失，单个源失败不阻断其他指标。
- [ ] 只启动已启用指标需要的数据源；关闭对应 GPU/温度指标后不继续执行无用查询。仅显示时间或关闭所有指标时同样遵守按需工作规则。
- [ ] 性能条手动显隐与全屏自动隐藏的优先关系保留；隐藏暂停采样，恢复时建立新基线，不出现异常网络速率。
- [ ] 查询取消、超时与模块停用可终止短命子进程并释放资源，在途结果不更新已停用或新代际界面。
- [ ] 停用保留配置与可见状态，再启用正常重建；不关闭整个套件或影响其他工具。
- [ ] 使用统一主题偏好和局部样式；相应控制器、平台源及真实窗口功能检查通过。

## 验证方式

复用现有采样、显隐、落位与窗口检查，通过可控指标源验证启用选择、暂停、取消和缺失状态，通过真实 WPF 窗口验证布局与显隐。硬件读数与多显示器人工场景按实际执行记录结果。
