# 09：整套功能回归与交付说明

**What to build:** 使用最终安装产物验证三个工具共同运行、重复启停、保存恢复及退出，整理可以按步骤执行的安装、日常操作和功能验收说明。

**Blocked by:** 07 — 隐藏界面回收与重复重建；08 — 统一开机启动与自包含安装包

**Status:** ready-for-agent

**规格：** [工具套件合并规格](../spec.md)。覆盖全部用户故事的最终整合交付；各前置工单已经包含对应功能测试。

## 已确认约束

- 使用整合后的最终构建与安装产物，不能用分离旧应用或早期宿主结果代替最终整套验证。
- 新套件独立空白数据，保留原应用、原数据和旧启动项；不补入被用户取消的迁移、自动备份或旧版接管流程。
- 保留功能测试，内存表现由日常使用判断；不新增专项内存对比、基线采集、固定内存预算或长期压力门槛。

## 验收条件

- [ ] 适用的原有领域规则、存储、粘贴链路与采样契约测试及新宿主功能检查通过，检查使用隔离数据。
- [ ] 最终安装产物只有一个常驻宿主和一个托盘；左键与双击无工具动作，右键分组管理，剪贴板保持快捷键呼出。
- [ ] 文字和图片记录、搜索与管理、普通和管理员目标粘贴、性能条指标及全屏显隐、便签编辑排序与贴边、手动导入导出正常。
- [ ] 工具启停、隐藏窗口重建、统一主题、全部停用后的恢复、重启持久化和开机启动状态符合规格。
- [ ] 保存失败不丢编辑，单个模块失败可提示并恢复；重复启停后没有重复监听、迟到更新或影响其他工具的退出。
- [ ] 多显示器/DPI、键盘无障碍、高对比度、文字大小、硬件缺失和旧快捷键冲突有相应检查或明确人工验收记录。
- [ ] 安装、升级、卸载、自启和退出功能检查完成，退出后释放文件锁且无残留工作；原应用及原数据保持独立。
- [ ] 无法实际执行的 UAC、登录、硬件或多显示器场景逐项标为未执行，提供复验步骤，不将缺失记录写成通过。
- [ ] 交付说明解释全新数据、管理员权限、托盘与快捷键、启停与隐藏区别、自启、手动便签备份及日常内存观察方式。
- [ ] 交付只报告实际完成的验证，不宣称未经测量的内存节省 MB 或百分比；所有产物位于整合目录。

## 验证方式

按正式规格的功能覆盖逐项执行并记录版本、运行条件与结果；对真实硬件和权限依赖明确区分自动检查与人工验收。最终记录只包含实际证据和可复验步骤，不重复运行没有新变化依据的已通过检查。
