# 07：隐藏界面回收与重复重建

**What to build:** 隐藏便签保存后释放窗口，设置与导入界面关闭后释放；剪贴板收起释放图片引用，工具停用取消后台工作并释放资源，重新打开或启用后仍正常使用。

**Blocked by:** 03 — 完整剪贴板管理与图片能力；04 — 性能条与按指标采样；05 — 独立便签与清单操作

**Status:** resolved

**实施结果：** 隐藏便签在保存成功后释放窗口与订阅、按需重建；设置与导入界面关闭即释放；剪贴板收起清空缩略图缓存并作废在途解码；性能条隐藏暂停采样与时钟；停用与退出取消任务并释放数据文件锁。`ToolSuite.LifecycleChecks` 40 条通过，`SuiteChecks`/`Pinto.ModuleChecks`/`Pinto.DesktopChecks` 随语义更新后全量通过；真实托盘点击与多显示器贴边未执行，详见[验证记录](../docs/validation/ticket-07.md)。

**规格：** [工具套件合并规格](../spec.md)。主要覆盖用户故事 29、33、40，并覆盖 6–10、24 的资源生命周期。

## 已确认约束

- 内存优化是实现目标，不安排专项基线、配对内存比较、固定 MB 上限或下降百分比门槛。
- 使用各模块已接入的控制和生命周期入口，本票与 06 无必需的先后依赖。
- 回收以成功保存、可恢复和取消无用工作为前提；保存失败时保留未保存内容。

## 验收条件

- [ ] 启动时不为已隐藏便签提前创建窗口；显示便签按需创建。
- [ ] 隐藏便签先提交编辑、捕获布局并保存，成功后释放窗口、视图模型及订阅；重新打开能恢复正确内容、完成状态、布局和贴边。
- [ ] 保存失败保留可恢复的编辑与必要引用，不为回收而丢弃数据；恢复保存后可继续隐藏和重建。
- [ ] 统一设置和导入界面按需创建、关闭后释放；重新打开仍显示正确配置并可继续操作。
- [ ] 剪贴板记录不依赖面板持续显示；面板收起后解除不再需要的图片引用与缓存，在途解码失效不向旧窗口回写，呼出仍流畅。
- [ ] 工具停用停止任务、计时器、系统事件订阅、钩子及监听；无可见指标需要时不进行无用采样或时钟更新。
- [ ] 重复显示、隐藏、关闭、启停后没有重复事件、重复记录、重复监听、迟到更新或残留查询，窗口及功能可继续正常使用。
- [ ] 整套退出能释放原生句柄与文件锁，无残留模块工作或查询进程；不将 GC 或工作集读数变化当成功能正确性的替代。
- [ ] 对上述可恢复、已取消和不再工作的行为执行功能检查；不附专项内存对比报告或未经测量的节省宣称。

## 验证方式

使用真实窗口重复打开及重建、隔离数据保存恢复、可控采样和解码源验证取消及停止结果。通过真实使用入口检查正确内容与后台不再工作的行为，不为可回收对象的私有布局编写镜像测试。
