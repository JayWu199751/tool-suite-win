# 08：统一开机启动与自包含安装包

**What to build:** 提供一个自包含安装包安装套件，统一开机启动开关只控制套件；登录启动后恢复已启用工具及套件自己的窗口可见状态。

**Blocked by:** 06 — 统一控制、主题与安全退出

**Status:** resolved

**实施结果：** 提供自包含单文件安装包（内嵌 .NET 10 桌面运行时）与安装/升级/卸载，统一开机启动默认关闭、只读写 `HKCU\...\Run\ToolSuite.Suite`、失败如实显示并回滚，登录启动只运行已启用工具并恢复隐藏状态。`ToolSuite.InstallerChecks` 16 条与最终安装包静默安装/卸载冒烟通过；真实 UAC、真实登录与干净机器未执行，详见[验证记录](../docs/validation/ticket-08.md)。代码审查修复把“替换目录 + 写卸载登记 + 写快捷方式”纳入同一事务（任一步失败恢复旧安装并清理半写登记，回滚失败保留原始异常并说明残留位置），详见[审查修复记录](../docs/validation/code-review-fixes.md)。

**规格：** [工具套件合并规格](../spec.md)。主要覆盖用户故事 1、12、34–36、39。

## 已确认约束

- 首版目标为 Windows 11 x64，统一安装包携带一份兼容的 .NET 10 桌面运行时。
- 安装、自启、单实例和存储身份独立；不接管、删除或修改原三个应用、原数据及旧启动项。
- 本票依赖三个工具统一控制行为，不必等待 07 的资源回收完成；最终交付由 09 同时验证 07 和本票。

## 验收条件

- [ ] 一个自包含安装包安装并启动全部工具，目标机无需预装桌面运行时；运行仍只有一个常驻 WPF 宿主及一个托盘。
- [ ] 所有安装脚本、构建输出和安装产物在整合目录，打包不依赖原项目运行时产物或开发机绝对路径。
- [ ] 统一开机启动首次默认关闭；开关只注册或注销套件自身启动身份，失败如实反馈，不把失败记为已生效。
- [ ] 开机启动按已确认管理员权限策略运行，仅启动已启用工具；窗口恢复使用套件自己保存的状态，不强制显示已隐藏便签或重新启用停用工具。
- [ ] 手动启动拒绝 UAC 时整个套件本次不启动，不回退为部分模块普通权限运行。
- [ ] 安装、升级和卸载不读取、迁移或备份旧应用数据，不修改旧程序或旧自启项；没有自动旧版切换流程。
- [ ] 升级检查套件自身文件占用，正确提示正常退出与重试；套件升级保留数据，卸载保留用户数据。
- [ ] 隔离环境中的发布版启动、重复启动、安装器及退出检查通过；涉及真实 UAC、登录或机器状态改变的验收步骤和实际结果明确记录。

## 验证方式

验证最终打包产物及套件身份，使用隔离目录和可控自启适配检查成功与失败结果。真实 UAC 和登录路径按人工步骤验收，未执行不标记通过，不更改个人旧启动项来模拟成功。
