# 05：独立便签与清单操作

**What to build:** 从套件的空白便签开始，支持新建、编辑、完成、排序、隐藏及恢复多张便签，保留窗口贴边、强调色和手动备份导入/导出。

**Blocked by:** 01 — 统一宿主与独立数据启动

**Status:** resolved

**实施结果：** 便签以模块形式接入，首次运行建立空白便签；清单编辑、完成、删除、拖拽排序、独立强调色、移动/缩放/屏幕与便签间贴边、关闭即隐藏并按标题恢复、手动导出/导入与损坏恢复均保留于套件独立数据。`Pinto.Checks` 24、`Pinto.ModuleChecks` 20、`Pinto.DesktopChecks` 77 通过；窗口回收与重复重建由工单 07 完成并验证；真实鼠标贴边与系统文件选择器人工场景未执行，见[工单 09 验证](../docs/validation/ticket-09.md)。

**规格：** [工具套件合并规格](../spec.md)。主要覆盖用户故事 25–30、38 中的便签行为；窗口回收由 07 继续完善。

## 已确认约束

- 使用便签当前工作区实现和样式，包含未提交修改；原项目保持不动。
- 便签是独立桌面窗口，不改为首页内的页面，不占任务栏、不置顶；关闭只隐藏，删除是单独确认的操作。
- 新套件不加载旧便签状态；手动导入/导出功能保留，自动旧数据迁移不在范围内。

## 验收条件

- [ ] 新数据首次启动创建空白便签，不显示原应用内容；后续恢复套件保存的内容和可见状态。
- [ ] 保留新建、改名、清单添加及编辑、完成状态、删除、拖拽与键盘排序和原有快捷键。
- [ ] 每张便签的强调色、大小和位置独立保存；窗口可移动、调整大小、屏幕贴边及便签之间贴边，保留原间距与任务栏工作区规则。
- [ ] 单张关闭表示隐藏；右键托盘按标题恢复隐藏便签，支持新建、显示全部和隐藏全部。
- [ ] 停用前提交编辑、保存内容及布局，失败则不完成停用；再次启用只恢复原本可见的便签。
- [ ] 手动导出及追加、替换导入保留；替换前确认并按原事务规则保护套件数据，重复追加产生独立副本。
- [ ] 导入不覆盖套件主题、自启或工具启停状态；损坏恢复、原子写入和保存失败保护能力保留。
- [ ] 使用统一主题，保留强调色、系统高对比度、文字大小和键盘无障碍能力。
- [ ] 不产生独立 App、托盘、单实例管道或自启项；数据及真实 WPF 功能检查通过。

## 验证方式

复用现有便签数据检查、导入事务、损坏恢复及真实 WPF 桌面检查；使用隔离数据验证编辑、贴边、显隐、停用恢复和重启。窗口释放与重复重建的完整验收在 07 完成。
