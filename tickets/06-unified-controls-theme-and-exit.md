# 06：统一控制、主题与安全退出

**What to build:** 通过一个托盘和按需打开的统一设置管理三个工具，统一明暗主题，协调启停与保存退出；任何单个工具的操作不误退出其他工具。

**Blocked by:** 03 — 完整剪贴板管理与图片能力；04 — 性能条与按指标采样；05 — 独立便签与清单操作

**Status:** resolved

**实施结果：** 唯一托盘按三工具分组并提供启停与统一设置，主题统一为跟随系统/浅色/深色且按有效外观去重下发，停用与退出前执行保存预检、失败保留运行状态，单模块启动失败可提示并从托盘或设置重试。`ToolSuite.SuiteChecks` 14 条整合检查与 `verify-host.ps1` 通过；真实鼠标托盘点击、系统高对比度与真实注销未执行，详见[验证记录](../docs/validation/ticket-06.md)。

**规格：** [工具套件合并规格](../spec.md)。主要覆盖用户故事 4、6–10、31、32、35、37、38 的跨工具行为。

## 已确认约束

- 本票在三个真实模块可运行的基础上完成控制整合，不用占位模块代替整套验收。
- 托盘左键与双击无动作，剪贴板仅由全局快捷键呼出；右键提供工具管理、统一设置和退出，无常驻首页。
- 启停状态、窗口可见状态与主题偏好分别持久化；隐藏不会等同停用，停用不会删除数据。

## 验收条件

- [ ] 右键按剪贴板、性能条、便签分组展示管理动作和启停状态，统一设置可配置各工具；不另设剪贴板面板呼出动作。
- [ ] 停用一个工具停止该工具工作，另外两个继续运行；设置编辑、重复启动和快捷键均不隐式重新启用已停用工具。
- [ ] 启停选择与窗口可见状态重启后保持；再启用恢复原可见状态，已隐藏便签保持隐藏。
- [ ] 三个工具全部停用时，唯一托盘与设置入口仍可用，可重新启用任意工具。
- [ ] 统一浅色、深色、跟随系统偏好，首次跟随系统；便签强调色保留，主题切换及系统偏好变化能正确反映。
- [ ] 模块样式局部应用，不互相覆盖；高对比度、系统文字大小、多显示器/DPI 的既有能力保留。
- [ ] 停用和套件退出先提交编辑并执行保存预检；必要保存失败时不静默退出或丢弃内容，并可继续使用、修复和重试。
- [ ] 窗口关闭、模块停用与整个套件退出的处理明确，性能条原退出调用和便签退出调用不直接关闭整个 Application。
- [ ] 单个模块启动失败给出可操作提示并允许重试，不伪装运行、不强制结束其他正常模块；真实跨工具整合功能检查通过。

## 验证方式

通过宿主真实命令入口、托盘、统一设置及窗口交互，检查状态、持久化、保存失败和其他工具的持续运行。复用已有规则与存储测试，新增宿主级整合测试，避免依赖内部字段或样式实现细节。
