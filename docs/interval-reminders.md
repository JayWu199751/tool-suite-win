# 循环提醒工具设计

状态：已实现，验证范围见[验证记录](validation/interval-reminders.md)。日期：2026-10-24。

本次需求在现有工具套件中增加循环提醒工具，是对原合并规格范围的扩展。本文记录已确认行为与待决问题；不改变原合并工作的历史范围。

## 已确认行为

- 支持多项循环提醒，每项独立设置名称、提醒间隔和启停状态。
- 用户确认提醒后，重新按完整间隔计时。例如间隔 30 分钟，10:00 提醒、10:05 确认，下次为 10:35。
- 同一项提醒未确认期间保留一个弹窗，不叠加新的弹窗。
- 使用置顶小窗，不抢占输入焦点，默认无声；点击“知道了”关闭并开始下一轮，不强制休息。

- 接入为套件第四个工具，在统一设置内管理，托盘可定位到对应分类。首次没有提醒；创建默认启用，关闭设置不停止计时。
- 托盘“循环提醒 → 新增提醒…”直接打开独立的新增窗口，不创建或跳转到设置页。设置列表的新增及编辑按钮也使用独立窗口，不再内联显示表单；保存成功后关闭，取消或关闭不保存。重复打开同一新增／编辑窗口时复用并保留草稿。
- 停用时仍可新增与编辑配置，不隐式启用工具；编辑窗口明确提示启用后才计时。保存失败保留窗口和输入；编辑中的提醒若被删除，提示重新选择，避免重建已删除内容。
- 睡眠、休眠、锁屏时间计入间隔；到期后恢复并解锁才提醒一次，不追补次数。使用包含睡眠时间的 Windows 单调计时源，避免修改系统时间改变提醒进度。
- 退出套件后不提醒；下次启动、工具重新启用时，已启用的提醒重新按完整间隔计时。保留名称、间隔和启停状态，不保存剩余时间。
- 支持秒、分钟、小时，默认 30 分钟。最小 1 秒，内部使用整秒，上限为 2147483647 秒；表单内明确校验。
- 修改间隔或重新启用单项时，从完整间隔开始；只改名称不重置。停用或删除立即移除对应待确认项。
- 一个置顶窗口列出所有到期项，逐项确认；关闭窗口或按 Escape 视为全部确认。弹窗首次定位到当前鼠标所在屏幕右下角，并按工作区与 DPI 限制尺寸；长列表内部滚动。
- 全屏应用中也显示；第一版无声音开关、稍后提醒、强制休息或历史记录。
- UI 使用 apple-design 技能指导，详见[界面设计](interval-reminders-design.md)。

## 验收场景

1. 新建多个短间隔提醒，各自到期；多次调度不叠加同项。
2. 到期后等待再确认，下次从确认时刻计时；逐项确认不影响其他项。
3. 改名称保持剩余时间，改间隔重置；停用与删除移除待确认项。
4. 模拟跨越多个周期的睡眠时间，只生成一次待确认项；停止后无提醒，重启恢复配置并重计时。
5. 保存失败保留旧配置与原计时；损坏数据报告错误且保留原文件。
6. 真实托盘新增入口打开独立窗口；设置中只管理列表，新增／编辑表单在独立窗口完成；浅色、深色及大文字布局可读，键盘有可见焦点。
7. 使用隔离目录验证模块生命周期、统一设置入口和聚合弹窗；锁屏、真实睡眠与全屏行为另记录人工验证边界。

沿用已有模块与存储约定，尚无需要单独记录 ADR 的架构取舍。
