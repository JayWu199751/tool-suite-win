# 统一设置页面

2026-10-22，用户确认复用**性能条现有设置窗口**，把通用设置与三个工具的配置合并。

## 行为

- 托盘“统一设置”、剪贴板“修改快捷键”、性能条托盘分组与性能条右键“打开设置”打开同一个窗口。
- 通用设置始终放在顶部，主题和开机启动继续由套件控制器管理。
- 剪贴板、性能条、便签依次排列，三个分组可独立展开/收起，首次收起并持久保存展开状态。
- 工具自身的设置入口自动展开并定位对应分组；普通统一设置入口保留已保存的展开状态。
- 每组提供启停、真实状态、失败重试。停用工具后仍能查看和修改可离线保存的配置，不隐式启动工具。
- 剪贴板提供快捷键修改；有效快捷键提交后保存，冲突/写入失败保留原值并显示原因。
- 性能条沿用指标、快慢刷新率、不透明度、字号、全屏自动隐藏，补入原右键菜单已有的水平居中和透明显示。
- 便签仅提供现有启停、状态、备份导入/导出与损坏数据恢复；单张便签的颜色、贴边仍在便签上修改。
- 修改即时保存。窗口关闭后释放，重新打开恢复设置；保存失败不伪装成功。

## 设计

Windows WPF 桌面工具，服务于频繁使用三个常驻工具的人。页面的任务是让用户在一处调整套件，
以“通用始终可见、工具按需展开”表达层级；保留性能条原有控件与卡片语言。

复用现有语义颜色，卡片上的正文/次要文字对比度如下（按 sRGB WCAG 公式计算）：

| 角色 | 亮色 | 暗色 | 对比度（亮/暗） |
| --- | --- | --- | --- |
| 画布 | #F5F5F7 | #0B0B0E | — |
| 卡片 | #FFFFFF | #141419 | — |
| 正文 | #1D1D1F | #F2F2F5 | 16.83 / 16.43 |
| 次要文字 | #63636A | #A0A0AC | 5.96 / 7.10 |
| 动作文字 | #0066CC | #A7A4F0 | 5.57 / 8.05 |
| 强调与焦点 | #0071E3 | #7B77E0 | 用于开关与焦点，文字使用动作色 |

正文 13 DIP、说明 12 DIP、分组标题 15 DIP 半粗、窗口标题 21 DIP 半粗；使用现有 Segoe UI / 微软雅黑字体栈。
整页一个垂直滚动区域，避免同方向嵌套滚动。宽度恢复性能条早期设置页的固定 380 DIP，长说明换行，
窗口高度固定为 720 DIP，并受当前显示器工作区限制；展开/收起不会改变窗口高度，超出部分内部滚动。
滚动条放在内容已有的右侧留白中，出现或隐藏均不改变窗口及卡片宽度，也不遮挡内容。
分组标题整行可点击，保留清晰焦点、键盘展开和屏幕阅读器名称。
不添加折叠动画；高对比度跟随系统配色，不引入模糊和阴影。

```text
固定宽度 380 DIP
工具套件 · 设置     关闭
┌ 通用设置 ──────────┐
│ 主题      跟随系统 │
│ 开机启动        ○ │
└───────────────────┘
▸ 剪贴板    已停用
▾ 性能条    已启用
  启用性能条       ●
  显示指标 / 刷新率
  外观 / 行为
▸ 便签      已停用
```

设计判断：三种工具有自然分组，按需展开比另增侧栏或多层导航更直接；保留现有卡片、移除重复的设置入口按钮。
Apple 指引采用其跨平台原则，Windows 的托盘入口和既有主题选择保持本项目习惯：

- `layout.md › Visual hierarchy`："Use progressive disclosure to make layouts cleaner and easier to interact with."
- `settings.md › Best practices`："Minimize the number of settings you offer."
- `scroll-views.md › Best practices`："Avoid putting a scroll view inside another scroll view with the same orientation."
- `accessibility.md › Vision`：小文字对比度至少 4.5:1；亮暗主题和高对比度均检查。

## 验收接口

用户已确认通过真实托盘菜单和 WPF 控件验证统一入口、分组展开收起、关闭/重启后的设置恢复、
工具停用时配置保存、亮暗主题与键盘操作。模块原有检查继续覆盖采样、快捷键冲突、数据恢复和生命周期。
所有检查使用 `artifacts/` 内隔离数据，不改动日常套件数据与真实开机启动项。

实施与检查结果见[统一设置验证记录](validation/unified-settings.md)。
