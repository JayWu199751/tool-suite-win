# 工单01接入补充：停用工具冷启动上下文

三个真实模块接入时发现：上下文只在 StartAsync 提供，重启时已停用的模块无法进行已确认的离线配置，且不能回退到原应用目录。

- 红：新增通过 SuiteController 冷启动停用工具的行为检查，实际失败于“冷启动已停用工具仍取得套件独立数据位置供离线设置使用”。原有三组检查仍通过。
- 绿：增加默认兼容的 Configure 入口，宿主在判断启用前轻量配置全部已注册模块；同一控制入口检查四组全部通过，停用状态仍为 Disabled。
- 模块上下文提供可选的统一主题读取/请求回调，停用模块可更新有效主题而不分配窗口。
- 宿主承接原便签的进程级 Pointer 输入初始化；宿主基础检查明确不注册真实工具，避免后续模块可见窗口被误判为首页。

此补充未启动旧应用、未访问个人数据或真实自启；UAC 及硬件人工限制与原01记录相同。
