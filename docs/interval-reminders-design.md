# 循环提醒界面设计

日期：2026-10-24。平台为 Windows WPF，使用 apple-design 的层级、可读性和交互原则，保留 Windows 键盘、托盘与窗口约定。

## 设计意图

让用户看清每项提醒还需等待多久，并在到期时轻松确认。界面特征是每项提醒的等宽数字倒计时；其余元素保持安静，不添加装饰图、阴影、玻璃或动画。

## 色彩与字阶

沿用套件语义色，局部资源跟随宿主主题，不另设外观开关。下列对比度由检查程序计算并记录。

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 画布 | #F5F5F7 | #0B0B0E |
| 卡片 | #FFFFFF | #141419 |
| 主文字 | #1D1D1F | #F2F2F5 |
| 次文字 | #63636A | #A0A0AC |
| 操作文字 | #0066CC | #A7A4F0 |
| 焦点 | #0071E3 | #7B77E0 |

正文 14 DIP，标题 17/600，弹窗标题 21/600，倒计时 17/600，说明 12。控件至少 32 DIP 高，文字可换行；采用系统字体与 Windows 文字缩放，高对比度交还系统颜色。

## 布局

管理列表嵌入统一设置的第四个工具分类。新增和编辑使用独立的 `ReminderEditorWindow`，不依附设置窗口；托盘新增直接打开该窗口。

编辑窗口采用 Windows 原生标题栏，支持移动、调整大小、任务栏切换和关闭；浅深标题栏跟随有效主题，高对比度交还系统。默认宽度 440 DIP，按系统文字缩放扩展并限制在工作区内，长内容滚动。字号、表面色、圆角与套件保持一致。

```text
紧凑／常规
循环提醒                         启停
确认后重新计时
[新增提醒…] → 独立窗口
┌ 喝水                         ┐
│ 每 30 分钟                   │
│ 还剩 28:32                   │
│ 启用                  [开关] │
│ [编辑] [删除]                │
└──────────────────────────────┘
独立新增／编辑窗口：
新增提醒／编辑提醒
设置一个间隔，到期提醒；确认后重新计时。
名称 [                       ]
间隔 [30]
单位 ○ 秒  ● 分钟  ○ 小时
工具停用时显示：启用工具后开始计时
[取消] [创建提醒／保存修改]
```

弹窗使用一个置顶窗口，卡片纵向排列；长列表滚动，标题、关闭和全部确认保持可访问。右上角关闭即全部确认，工具提示明确含义。弹窗首次出现在鼠标所在屏幕右下角，不抢焦点，不在每次刷新时移动。

## 依据与取舍

- `layout.md › Visual hierarchy`：按重要性排序、对齐、分组；管理列表显示名称、间隔和剩余时间；独立窗口专注名称与间隔输入。
- `accessibility.md › Vision / Mobility / Cognitive`：文字对比度、键盘路径、足够命中区；提醒等待明确确认，不自动消失。
- `entering-data.md › Best practices`：名称与间隔明确标注，非法输入在表单内给出可修正提示。
- `notifications.md › Notification actions`：提供能直接完成任务的简短操作；逐项“知道了”直接开始下一轮。
- `dark-mode.md › Best practices`：检查两套主题，避免增加独立主题设置。
- 工作室判断：计时工具不需要品牌插画；移除装饰性铃铛，保留真实倒计时作为视觉特征。

Windows 上不复制 macOS 菜单栏或交通灯按钮。全屏仍提醒、关闭即确认是用户明确选择；删除需确认以避免丢失配置。无动画与透明材质，天然兼容减少动态效果和减少透明度偏好。

## 实现后的设计复核

评价：良好。界面的单一任务是设置和确认循环提醒；剩余时间与明确状态构成信息层级，没有额外的装饰性视觉负担。

原计划把间隔和剩余时间放在同一行，紧凑窗口与大文字下容易争夺空间，落地时改为纵向排列。单位仅有三个，使用原生单选按钮直接呈现，省去打开下拉菜单的步骤。输入动态校验并在信息不完整时禁用保存；编辑按钮的辅助功能名称同步为“保存修改”。

以下依据为中文译述，文件及标题来自本次实际读取的技能参考资料：

- `layout.md › Visual hierarchy`：“对齐元素以便浏览，利用缩进传达层级。”名称、间隔、剩余时间与操作按单列对齐。
- `entering-data.md › Best practices`：“尽可能提供选项，而非要求输入文字。”单位使用三项选择；“动态验证字段值”对应表单即时校验。
- `accessibility.md › Cognitive`：“尽量减少限时显示的界面元素。”弹窗不自动消失，由用户确认。
- `dark-mode.md › Best practices`：“确保应用在两种外观模式下都表现良好。”已分别渲染并检查两套主题。

次要文字在浅色卡片为 5.96:1，深色卡片为 7.10:1；操作文字在浅色悬停底色为 4.56:1，深色卡片为 8.05:1。保留文本状态辅助区分启停，不依赖颜色；Tab、空格、Enter 和 Escape 沿用 WPF 控件与窗口行为，使用显式焦点环。

已查看浅深管理区与弹窗、紧凑宽度及 200% 文字渲染图；屏幕阅读器、真实多显示器混合 DPI 与系统高对比度切换仍需人工复验，不能据渲染图宣称已验证。

独立窗口已检查浅深两套渲染和 200% 文字布局。名称及间隔放在同一卡片；底部仅保留取消和保存两个操作。新增窗口与管理列表分开后，移除了设置页中的表单及重复输入状态；重复点击不会清空已有草稿。
