# 工具套件交付说明

日期：2026-10-21。适用版本：1.0.0（Windows 11 x64，自包含 .NET 10 桌面运行时）。
本文给出安装、日常操作、备份与自启的可执行步骤，以及可复验的人工验收清单。
自动检查的实际结果与未执行场景见[工单 09 验证记录](validation/ticket-09.md)。

## 1. 交付内容与位置

| 产物 | 路径 |
| --- | --- |
| 安装包（唯一需要分发的文件） | `artifacts/installer/ToolSuite-Setup-1.0.0.exe`（120.1 MB） |
| 自包含发布目录 | `artifacts/publish/win-x64` |
| 安装载荷 | `artifacts/publish/ToolSuite-win-x64.zip` |
| 构建信息 | `artifacts/installer/build-info.txt` |

安装包内嵌一份 .NET 10 桌面运行时，目标机不需要预装 .NET。安装器不需要管理员权限，
安装到当前用户目录；套件正式可执行文件 `ToolSuite.exe` 要求管理员权限（见第 5 节）。

## 2. 安装

1. 双击 `ToolSuite-Setup-1.0.0.exe`，打开“工具套件安装程序”。
2. 确认“安装目录”。默认 `%LOCALAPPDATA%\Programs\ToolSuite`（当前用户，无需管理员权限）；
   也可以改成其他当前用户可写目录。
3. 按需勾选“创建开始菜单快捷方式”（默认勾选）与“创建桌面快捷方式”（默认不勾选）。
4. 点击“安装 / 升级”。状态区显示“已安装 1.0.0：<目录>”。
5. 从开始菜单启动“工具套件”，在 UAC 提示中点击“是”。
6. 首次启动会同时启用三个工具：性能条出现在桌面，便签按首次使用规则建立一张空白便签，
   剪贴板面板不显示（按 `Ctrl+Shift+V` 呼出）。系统托盘出现唯一一个“工具套件”图标。

命令行安装（无人值守，可用于批量部署）：

```powershell
& "ToolSuite-Setup-1.0.0.exe" /silent /dir="D:\Apps\ToolSuite"
# 可选：/no-start-menu 不建开始菜单快捷方式；/desktop 建桌面快捷方式
# 退出码：0 成功；1 失败；2 套件正在运行、拒绝替换
```

静默安装不会启动套件，也不会开启开机启动。

## 3. 升级

1. 托盘右键 → “退出工具套件”，确认套件进程已结束（任务管理器里不再有 `ToolSuite.exe`）。
2. 运行新版本安装包，安装目录必须与已安装目录一致。安装程序默认仍是
   `%LOCALAPPDATA%\Programs\ToolSuite`，不会读取上一次的自定义目录；
   若当初装到自定义目录，请在“安装目录”里手动填入同一路径。
3. 点击“安装 / 升级”，状态区显示“已升级到 <版本>”。

规则与失败处理：

- 套件正在运行时安装器**拒绝**替换，并提示“退出工具套件后点击‘重试’”，旧版本文件保持可用。
- 替换目录、写入卸载登记与创建快捷方式属于同一次事务：任一步失败都会恢复旧安装
  （文件与 `version.txt` 版本号不变），并按旧版本重建卸载登记与快捷方式，界面仍显示旧版本。
  只有登记本身持续写入失败时（例如注册表被策略锁定），旧文件照样恢复，但“已安装的应用”条目
  可能缺失，重新安装（或再次升级）一次即可恢复登记。
- 升级只动安装目录、套件自己的卸载登记与快捷方式，**不读写**用户数据
  （`%LOCALAPPDATA%\ToolSuite`），也不读写原三个应用的任何数据或启动项。

## 4. 卸载

方式一（推荐）：Windows 设置 → 应用 → 已安装的应用 → “工具套件” → 卸载。
方式二：安装目录内运行 `ToolSuite.Setup.exe`，点“卸载”。
方式三：`"ToolSuite-Setup-1.0.0.exe" /uninstall`（加 `/silent` 为静默卸载）。

- 卸载会删除：安装目录、`HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\ToolSuite`、
  `HKCU\...\Run\ToolSuite.Suite` 开机启动值、套件自己的开始菜单/桌面快捷方式。
- 卸载**保留** `%LOCALAPPDATA%\ToolSuite` 全部用户数据（便签、剪贴板历史、性能条设置、统一设置）。
  重新安装后数据仍在。
- 卸载不触碰原三个应用的安装、数据与启动项。
- 套件正在运行时卸载会被拒绝并提示先退出；从安装目录内的卸载入口运行时，目录由系统在进程
  退出后清理，若目录被其他程序占用可能残留空目录，可手动删除。
- 要彻底清除套件痕迹，在卸载后手动删除 `%LOCALAPPDATA%\ToolSuite`。

## 5. 管理员权限与拒绝 UAC

- `ToolSuite.exe` 的清单为 `requireAdministrator`（保留向管理员窗口直接粘贴的能力），
  便签与性能条随同一进程提权。
- 手动启动时在 UAC 提示中点击“否”：本次**整个套件都不启动**，不会降级为普通权限只运行部分工具，
  也不会留下托盘图标或后台进程。
- 开机启动同样会触发 UAC（登录后由 `HKCU\...\Run` 拉起）。拒绝时该次登录不启动套件；
  下次手动启动仍按套件保存的启停状态恢复。
- 安装器本身是 `asInvoker`，安装/卸载不需要管理员权限。

## 6. 托盘：左键无动作，右键分组

- **左键单击、双击均不打开任何窗口**。剪贴板面板只用快捷键呼出，这是刻意设计，避免误触。
- **右键**打开菜单，按工具分组，组标题直接带状态，例如
  `剪贴板 · 运行中`、`性能条 · 已停用`、`便签 · 启动失败`：
  - 剪贴板组：启用/停用、修改剪贴板快捷键、清空历史（无二次确认，执行后提示“已清空历史”）。
    该组**没有**“打开面板”动作。
  - 性能条组：启用/停用、显示/隐藏性能条、性能条设置。
  - 便签组：启用/停用、新建便签、显示全部便签、隐藏全部便签、导出便签备份…、导入便签备份…，
    以及每张**当前隐藏**便签的标题（点击即重新打开该便签）。
  - 菜单底部：统一设置、退出工具套件。
- 重复启动套件（例如再次双击快捷方式）不会产生第二个进程或第二个托盘图标；已有实例会把
  “统一设置”窗口显示出来作为反馈，不会强制弹出剪贴板或便签。

## 7. 剪贴板快捷键

- 默认呼出/收起键：`Ctrl+Shift+V`。
- 修改：托盘右键 → 剪贴板组 → “修改剪贴板快捷键”，在输入框写入组合键（例如 `Control+Shift+V`
  或 `Ctrl+Alt+V`），点“保存”。窗口关闭后新键立即生效。
- 新快捷键已被其他程序占用时无法注册，套件会提示“<键> 已被占用，请在统一设置修改快捷键”，
  不会终止占用方，也不会静默抢占。换成未被占用的组合即可。
- 剪贴板**停用**后不再记录内容，也不响应呼出键；停用状态不会因为一次按键被隐式打开。

## 8. 工具启停与“隐藏 ≠ 停用”

两个入口等价：托盘右键组内的“启用/停用”，以及“统一设置”里的勾选框。

- **停用**：先提交编辑、捕获布局并保存，成功后才释放该工具的窗口、监听与后台查询，并记住停用状态；
  保存失败则停用不生效，窗口与未保存内容保留，可修复后重试。
- **重新启用**：恢复停用前的窗口可见状态。原先隐藏的便签仍隐藏、隐藏的性能条仍隐藏，不会被强制显示。
- **隐藏**只是收起窗口，工具仍在运行：便签继续保存内容但窗口被释放，再打开时按需重建；
  性能条隐藏时暂停采样，恢复后重建差分基线；剪贴板收起后释放缩略图引用，再呼出重新加载。
- 三个工具全部停用时，套件仍在托盘保留图标与“统一设置”，可随时重新启用任一工具，
  不保留各工具的后台工作。
- 单个工具启动失败会显示“启动失败”与错误原因，其他工具继续运行；设置中给出“重试启动”。
- 关闭便签窗口、关闭性能条窗口都不会退出套件；只有托盘“退出工具套件”或系统注销/关机才结束进程。

## 9. 便签：编辑、隐藏、手动导出与导入

- 托盘右键 → 便签组 → “新建便签”创建空白便签；标题可改名，清单项可新增、编辑、完成、删除与排序，
  每张便签有独立强调色。
- 关闭便签窗口等于**隐藏**（内容保留，窗口释放）。再次打开：托盘右键 → 便签组 → 点该便签标题；
  或用“显示全部便签”。
- 便签可自由移动、调整大小并对屏幕边缘或其他便签贴边；隐藏再打开后位置、尺寸与贴边状态保持。
- **导出**：托盘右键 → 便签组 → “导出便签备份…”，选择保存位置，得到一份备份文件
  （含便签内容与布局）。建议在重装、迁移机器前手动导出一次。
- **导入**：托盘右键 → 便签组 → “导入便签备份…”，选择备份文件。对话框显示备份内便签数量与当前
  便签数量；替换全部前需要确认，追加导入会为每条记录生成独立副本。
- 导入只影响便签内容与布局，**不改变**统一主题、开机启动和三个工具的启停状态。
- 数据文件损坏时，若便签工具已停用或启动失败，托盘便签组会提供“从备份恢复损坏数据…”，
  用套件内部的最近备份恢复；正常保存使用原子写入，损坏文件不会被静默覆盖。
- 套件不读取、不迁移旧便签应用的数据，也不把旧便签状态当作新状态恢复。

## 10. 统一主题

- 托盘右键 → “统一设置” → “主题”：`跟随系统`（首次默认）、`浅色`、`深色`。
- 选择立即作用于宿主、三个工具的窗口与托盘（深色下托盘使用对应配色，系统高对比度时交还系统配色）。
- 主题偏好保存在 `%LOCALAPPDATA%\ToolSuite\suite.json`，重启保持；系统主题变化时“跟随系统”
  会重新计算。
- 系统开启高对比度时，剪贴板面板改用系统高对比度配色（窗口、文字、选中高亮、次要文字都来自
  `SystemColors`）；切换高对比度的瞬间即生效，不需要重启或重新呼出。便签与性能条沿用宿主的
  高对比度处理。
- 每张便签的强调色独立于统一主题，不会被主题覆盖。
- 性能条设置窗不再提供主题与开机启动开关：这两项只有“统一设置”一个入口，模块自己的
  旧设置字段不再生效。

## 11. 开机启动（默认关闭）

- 开关位置：托盘右键 → “统一设置” → “开机启动（登录后运行已启用的工具）”。首次为**关闭**。
  这是唯一的开机启动开关；性能条设置窗里的自启行已隐藏，模块设置中的旧自启字段不生效。
- 开启后只写一条套件自己的启动项 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\ToolSuite.Suite`，
  指向安装后的 `ToolSuite.exe`；不修改、不接管原三个应用的启动项。
- 登录时只启动**已启用**的工具，并恢复套件保存的窗口可见状态（隐藏的便签与性能条保持隐藏）。
- 失败会如实反馈：注册或注销失败时开关恢复为操作前状态，并在开关下方显示失败原因，
  不会出现“显示已开启但实际未生效”。

## 12. 日常内存观察方式

不提供基准或节省数值，请按日常使用判断是否轻量。可用任务管理器观察趋势：

1. `Ctrl+Shift+Esc` 打开任务管理器 → “详细信息” → 找到 `ToolSuite.exe`。
2. 添加“提交大小”“工作集（内存）”“句柄数”“CPU”列，观察空闲与使用中的差别。
3. 对照操作：只保留一个工具启用 → 停用该工具 → 重新启用；隐藏全部便签后重新打开；
   收起剪贴板面板后再次呼出。正常情况下窗口与后台工作按需创建、隐藏后释放，
   句柄数不应随重复显隐持续增长，停用后 CPU 与查询活动应停止。
4. 关注长期趋势而非瞬时数值；如需精确判断请用性能监视器（`perfmon`）记录 `Process\Private Bytes`
   与 `Process\Handle Count` 一段时间。

本版本不宣称未测量的内存节省量；实现层面的按需创建与释放由功能检查覆盖
（见[工单 07 验证](validation/ticket-07.md)）。

## 13. 数据位置与备份

| 内容 | 位置 |
| --- | --- |
| 统一设置（主题、启停偏好、窗口可见状态） | `%LOCALAPPDATA%\ToolSuite\suite.json` |
| 剪贴板历史、快捷键与图片 | `%LOCALAPPDATA%\ToolSuite\modules\clipboard\`（`clipboard-history.json`、`settings.json`、`images\`） |
| 性能条设置 | `%LOCALAPPDATA%\ToolSuite\modules\perf-monitor\settings.json` |
| 便签内容与布局 | `%LOCALAPPDATA%\ToolSuite\modules\pinto\state.json` |

- 该目录是套件**独立**的数据根，从空白开始，与原三个应用的数据互不影响。
- 备份：退出套件后复制整个 `%LOCALAPPDATA%\ToolSuite` 目录即可；便签也可单独用
  “导出便签备份…”保存为文件。
- 恢复：退出套件 → 覆盖回该目录 → 启动。
- 开发或自动化检查可用 `--data-root <目录>` 指定隔离数据根，不影响上述日常数据。

## 14. 人工验收清单

以下项目需要真实桌面、真实 UAC 或硬件，自动检查只覆盖到同一条控制入口，请按步骤确认。

| 场景 | 步骤 | 期望 |
| --- | --- | --- |
| 托盘左键 | 左键单击、双击托盘图标 | 不出现任何窗口；剪贴板面板只有 `Ctrl+Shift+V` 能呼出 |
| 右键分组 | 右键托盘 → 依次展开三个分组 | 组标题显示当前状态；剪贴板组无“打开面板”；便签组列出隐藏便签标题 |
| 快捷键修改 | 修改为 `Ctrl+Alt+V` 并保存，再按旧键与新键 | 旧键无反应，新键呼出/收起 |
| 快捷键冲突 | 先让其他程序占用目标组合，再在套件里保存该组合 | 明确提示已被占用；套件不抢占、不崩溃 |
| 管理员窗口粘贴 | 以管理员身份打开记事本/终端，呼出面板选中文字或图片后回车 | 内容粘贴到该窗口；无焦点可粘贴时给出失败提示 |
| 截图入库 | `Win+Shift+S` 截图 → `Ctrl+Shift+V` | 新截图出现在历史中，可粘贴回画图等程序 |
| 停用/启用 | 逐个别停用三个工具，再逐个启用 | 停用后无新记录/采样/新便签；启用后窗口可见状态与内容与停用前一致 |
| 全部停用 | 三个都停用 | 托盘图标与统一设置仍在，可重新启用 |
| 保存失败保护 | 用其他程序独占 `state.json` 后关闭便签窗口 | 窗口保留、编辑不丢；解除占用后可继续隐藏 |
| 便签隐藏重建 | 隐藏全部便签 → 从托盘点标题重开 | 内容、位置、尺寸、贴边、强调色保持 |
| 便签导入导出 | 导出备份 → 改动内容 → 导入 | 显示数量确认；替换/追加结果符合预期；主题与启停不变 |
| 主题 | 依次切换跟随系统/浅色/深色，并切换系统高对比度 | 三个工具与托盘同步变化；剪贴板面板转为系统高对比度配色；便签强调色不变 |
| 性能条设置入口 | 托盘 → 性能条组 → “性能条设置” | 窗口内只有指标、刷新率、不透明度、字号、全屏隐藏；没有主题与开机启动开关 |
| 开机启动 | 设置中开启 → 注销或重启 → 允许 UAC | 只有套件启动、一个托盘；停用工具未启动；隐藏便签仍隐藏 |
| 拒绝 UAC | 启动套件时点“否” | 套件完全不启动，无托盘、无残留进程；不出现部分工具运行 |
| 多显示器/DPI | 把性能条与便签拖到副屏，改缩放比例后重开 | 位置合理、可见；贴边与文字大小正常 |
| 升级与卸载 | 退出套件 → 覆盖安装新版本；再从系统设置卸载 | 升级保留数据；卸载删除程序与自启值，数据仍在 |

## 15. 已知限制

- 安装包未签名，首次运行可能遇到 SmartScreen 或杀毒软件延迟扫描；需要时选择“仍要运行”。
- 安装目录同时包含展开的自包含运行时与一份卸载入口副本，磁盘占用较大（约 120 MB 以上）。
- 自启值保存绝对路径，手动移动安装目录后需要在设置里关闭再开启一次开机启动。
- 套件只支持 Windows 11 x64。
- 默认要求管理员权限，登录自启会弹出 UAC；这是保留管理员窗口粘贴能力的结果。
- 卸载后如目录被占用，可能残留空目录，可手动删除。
