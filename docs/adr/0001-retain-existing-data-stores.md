# 首版沿用三个工具的原有数据目录与格式（已被替代）

用户在第三轮补充讨论中明确选择 10.B：新套件使用独立数据、从空白开始，原数据保留。本记录仅保留历史背景，实施遵循 ADR-0003。

2026-10-21，用户在合并讨论第一轮确认：套件首版保留三个工具现有数据目录与格式，切换前备份。统一存储会把数据迁移、损坏恢复与回退验证叠加到应用合并中，首版选择复用已有存储行为，将工作集中在统一入口和降低内存占用。

原独立程序与套件不能同时写入同一份数据；具体切换及回退流程在后续讨论中确定。未来统一数据目录须单独设计迁移方案。
