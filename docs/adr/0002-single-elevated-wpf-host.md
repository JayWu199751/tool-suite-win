# 一个管理员权限 WPF 宿主承载三个工具

2026-10-21，用户确认合并优先降低常驻内存，采用一个常驻 WPF 宿主承载剪贴板历史、性能条和清单便签，共用 Application、UI 消息循环和托盘。后续用户选择 12.A：不做专项内存对比，保留功能测试，内存表现由日常使用判断；不得仅凭进程数量宣称已实测降低内存。为保留向管理员窗口快捷粘贴的能力，整个宿主沿用剪贴板正式版的管理员权限要求，便签等同进程功能也随之提权。

手动启动若拒绝授权，本次整个套件不启动。性能条独立版本的 ADR-0001 中“拒绝提权仍以普通权限继续运行”不沿用到套件宿主；原项目本身不修改。套件不保留独立的常驻提权交接进程，但硬件查询仍可能产生短命子进程。
