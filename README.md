# 工具套件合并

将剪贴板历史、性能条和清单便签整合为一个安装包、一个托盘和一个常驻管理员权限 WPF 宿主，以减少重复基础设施和闲置后台工作为实现方向。

2026-10-21，用户已确认产品行为、功能验证入口，以及九项工单的粒度和依赖。当前已完成规格与工单文档，全部待实施；尚无套件应用代码或构建产物。

## 实施入口

- [正式规格](spec.md)：产品行为、实现决定、功能测试和范围边界。

- [术语表](GLOSSARY.md)：工具套件、便签、清单项、隐藏、停用及套件数据。

## 已确认边界

- 托盘左键及双击无操作，剪贴板保持全局快捷键呼出；右键管理三个工具及统一设置。
- 三个工具可独立启停并记住状态，统一主题，统一开机启动首次默认关闭。
- 新套件使用独立数据，从空白开始；原应用、原数据和旧启动项保持独立，不执行自动迁移或旧版接管。
- 保留原有手动便签备份导入/导出。隐藏与停用均保留内容，必要保存失败时不丢弃编辑。
- 保留功能测试，内存表现由日常使用判断；不安排专项内存对比或承诺具体节省数值。
- 所有新生成的代码、文档、测试、脚本及构建产物位于本目录。原三个项目保持不动，整合时包含便签当前工作区修改。
